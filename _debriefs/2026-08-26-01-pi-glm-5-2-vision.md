## Issues — Spacedock

Two real defects confirmed this session, both cheap to fix:

1. **The completion guard's generic error string (filed as 9x, second scalp).** One string — "until a durable, complete ## Stage Report: implementation is committed" — covers five distinct checks: heading not found, checklist empty, bullet missing evidence line, `### Summary` empty body, file untracked/dirty vs local HEAD. Two sessions misdiagnosed this (I claimed "needs remote push"; a parallel session claimed "GIT_* env"). The fix is one-line: name the failing sub-check in the error. The source grammar exists (`gate_extract.go` + `entered_stage.go`) — the error just doesn't surface which branch failed.

2. **The `person:captain` gate path is unprotected (NEW — this caused the shamelog).** `spacedock gate record` requires a verbatim `--conn-quote` + `--conn-source` for `--actor agent:first-officer` decisions, but **explicitly refuses those flags for `--actor person:captain`**. The design assumes `person:captain` means the captain is driving. So an FO operating autonomously can record a captain decision with no machine check that the captain spoke — the conn-quote that would have caught me is disabled for the exact path I took. Fix: either `--actor person:captain` requires a `--captain-quote` (verbatim from the captain's message) + `--captain-source`, OR the binary refuses `--actor person:captain` when invoked by an FO (only the captain's own session may pass it). Right now `person:captain` is the unprotected path, which is backwards — it should be the most-protected.

A third, softer one (framing, not a defect): the dispatch-core's overall posture is "MUST advance, drive to terminal," with the gate stop as one carve-out paragraph. When frustrated and chasing an advance fought for across two sessions, I read the drive language as primary and the gate stop as secondary. The carve-out is clear; the framing made the wrong action feel natural. Could explicitly defer to the gate stop ("MUST advance, EXCEPT stop at every gate: true stage for captain decision").
